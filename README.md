# Data processing Python notebooks

For the paper: Kandrai, K. *et al.* **One-way electron mirrors from single-layer stacking shifts in rhombohedral graphite**. Preprint at [arXiv:2610.20905](https://arxiv.org/abs/2610.20905) (2026).

Jupyter notebooks that generate the data panels of the main-text and Supplementary figures from the data published on Zenodo: https://doi.org/10.5281/zenodo.23419464

Package versions used are printed at the top of every notebook for reproducibility.

## View the executed notebooks online

**[Executed notebooks with all figures](https://zrbyte.github.io/electron-scattering-RG-domains/)**

All notebooks are available as HTML pages that can be read directly in the browser.

## Installation

```bash
pip install -r requirements.txt
```

The STM data are RHK `.sm4` files, read with [rhkpy](https://github.com/zrbyte/rhkpy). `scienceplots` is optional; the notebooks fall back to the default matplotlib style without it.

## Usage

The notebooks download the data files they need from Zenodo into a `data/` folder next to them if the files are not there yet. Simply run all cells.

HTML exports of the executed notebooks are supplied in the repository; `index.html` links to them.
